# Sistema de Investigación Criminal &mdash; Repositorio Central

> Proyecto de Aula: Desarrollo Web Full-Stack &amp; Paradigmas de Programación (Semestre 2026-2)  
> Estilo: **Expediente Forense Noir**

Este repositorio contiene los dos módulos principales de la plataforma:
- [`backend/`](./backend): API REST construida con Node.js 20, Express, TypeScript, Prisma ORM, PostgreSQL y Supabase Storage.
- [`frontend/`](./frontend): Aplicación web interactiva construida con Next.js 14 (App Router), React, TypeScript y Tailwind CSS.
